# Echo pour Android

Pour installer ou mettre à jour l'appli Echo, ouvre ce lien depuis le téléphone :

**https://github.com/Nihchris/echo-apk/releases/latest/download/echo.apk**

Il mène toujours à la dernière version. Pour installer une version précise, voir les
[releases](https://github.com/Nihchris/echo-apk/releases).

Ce dépôt ne contient que l'appli à installer, publiée automatiquement à chaque nouvelle version.
